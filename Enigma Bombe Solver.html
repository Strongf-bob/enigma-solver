How to Use

This simulator demonstrates how the Enigma machine works and how the Bombe algorithm can crack it.

Encryption Process

1. Select three different rotors from the dropdown menus

2. Set initial rotor positions (AAA to ZZZ)

3. Optionally configure the plugboard (e.g., "AB CD" swaps A with B and C with D)

4. Enter plaintext (letters only)

5. Click Encrypt to see the ciphertext

Decryption Process

1. Paste the ciphertext you want to crack

2. Enter a known plaintext fragment (crib) - part of the original message

3. Specify where the crib appears in the ciphertext

4. Click Crack and the algorithm will find the rotor settings

Technical Details

The Bombe tests 17,576 possible rotor position combinations (26^3) and identifies settings where the crib matches the decrypted text segment. This is how Alan Turing broke Enigma during WWII.

Examples

Rotors: I, II, III

Example 3: Cracking with Bombe

Ciphertext: XQYTUHWQD

Crib: HELLO

Crib Position: 0
